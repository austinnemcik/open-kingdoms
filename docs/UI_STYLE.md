# UI style guide

The look: a warm heraldic strategy UI. Dark walnut frames with gold trim,
parchment reading surfaces, a crimson title plaque, chunky gem-like buttons and
bold outlined icons. Everything here is original and generated by scripts in
this repo (rule 7 in CLAUDE.md): no art, layouts or text from any other game.

References, rendered from the real theme and widgets:

- `docs/screenshots/ui_showcase.png`: every style and widget (`client/ui/showcase.tscn`)
- `docs/screenshots/ui_hud_mock.png`: the city HUD composition to build against (`client/ui/hud_mock.tscn`)

## Using it

The theme is the project default (`gui/theme/custom` in `client/project.godot`),
so every Control is styled without any setup. You choose a look by setting
`theme_type_variation` on a node. Never override colours, fonts or styleboxes
per node except for state set from code (see `UiColors`).

| Need | Use |
|---|---|
| A window | `PanelFrame` widget (title plaque, close button, parchment body) |
| A HUD card, popup, toast | `PanelContainer` (default style) |
| Text on wood / cards / HUD | `Label` with `Header`, `Subheader`, `Body`, `Caption`, `ResourceValue` |
| Text on parchment | the `...Ink` variants: `HeaderInk`, `SubheaderInk`, `BodyInk`, `CaptionInk`, `ResourceValueInk` |
| The main action in a view | `Button` with `ButtonPrimary` (one per view) |
| Other actions | plain `Button` |
| Claim a reward | `ButtonGold` |
| Destroy, cancel a march, leave | `ButtonDanger`, behind a `ConfirmDialog` |
| A square icon action | `IconButton` widget |
| Resource counters | `ResourceBar` / `ResourceChip` widgets |
| A running timer | `TimerProgressBar` widget |
| A price | `CostRow` widget |
| A server error or event | `Toast.popup(self, "Not enough wood", Toast.Kind.ERROR)` |
| Numbers and times | `UiFormat.compact`, `UiFormat.exact`, `UiFormat.duration`, `UiFormat.duration_short` |
| An icon | `UiIcons.get_icon(&"farm")` or `UiIcons.make_rect(&"farm", 48)` |

Widgets live in `client/ui/widgets/` (a `.tscn` and a `class_name` script each).
Instance the scene or call `Widget.new()`; both work. They are presentation
only: feed them state through setters and listen to their signals. They never
touch `Net` or `GameState`.

```gdscript
var bar := ResourceBar.new()
bar.set_amounts({"food": 12431, "wood": 980}, {"food": 50000})  # amounts, capacities

var timer := TimerProgressBar.new()
timer.set_timer(remaining_seconds, total_seconds)   # call again on each server update
timer.finished.connect(_on_done)

var frame := PanelFrame.new()
frame.title = "Farm"
frame.add_content(my_content)
frame.close_requested.connect(frame.queue_free)

var cost := CostRow.new()                            # set on_dark = true on cards
cost.set_costs(costs, owned, duration_seconds)
upgrade_button.disabled = not cost.is_affordable()   # the server still validates

var dialog := ConfirmDialog.open(self, "Demolish", "Remove this farm?", "Demolish", "Keep")
dialog.set_destructive(true)
dialog.confirmed.connect(_demolish)
```

## Colour tokens

Defined in `tools/ui/common.py` (art) and `client/ui/ui_colors.gd` (code).

| Token | Hex | Use |
|---|---|---|
| `OUTLINE` | `#2b1a0f` | Outline of every icon, button and frame; text outlines |
| `WOOD_DARK` / `WOOD` / `WOOD_LIGHT` | `#33231a` / `#463020` / `#7a5a36` | Frames, cards, chips, input borders |
| `PARCHMENT_LIGHT` / `PARCHMENT` / `PARCHMENT_DARK` | `#fbf3de` / `#f1e3c4` / `#c9ae7c` | Input fields / window bodies / burnished edges |
| `GOLD_LIGHT` / `GOLD` / `GOLD_DARK` | `#ffe58a` / `#f2b632` / `#8a5a14` | Trim, rims, selection, focus ring |
| `CRIMSON` | `#c5463a` | Title plaque, badges, danger buttons, close button |
| `VERDIGRIS` | `#2f7a87` | Neutral buttons |
| `GREEN` | `#5cab3d` | Primary buttons, progress, success |
| `TEXT` / `TEXT_MUTED` / `TEXT_GOLD` | `#fff6e0` / `#d9c7a3` / `#ffd978` | Text on dark surfaces |
| `DANGER` / `SUCCESS` / `WARNING` | `#ff8a78` / `#9be063` / `#ffc24a` | State text on dark surfaces |
| `INK` / `INK_MUTED` | `#2e2014` / `#6b543a` | Text on parchment |
| `INK_DANGER` / `INK_SUCCESS` | `#b3261e` / `#276a1c` | State text on parchment |
| `SCRIM` | `#120a05` at 60% | Backdrop behind modal dialogs |

Colour carries meaning, so keep it consistent: green means go or gain, gold
means reward or selection, crimson means destructive or an alert, verdigris is
neutral. Blue striped fill is reserved for timers. Never signal state by colour
alone: unaffordable costs are red and the action is disabled and explained.

## Typography

Two OFL fonts in `client/ui/fonts/` (licences alongside):

- **Cinzel** (weight 800, +1 letter spacing): titles and headers only. It has no
  true lower case, so never use it for sentences or numbers in running text.
- **Nunito** (weight 650 body, 850 bold): everything else.

| Variation | Font | Size | Use |
|---|---|---|---|
| `HeaderLarge` | Cinzel | 34 | Screen titles |
| `Header` / `HeaderInk` | Cinzel | 24 | Section and card titles |
| `Title` | Cinzel | 21 | Window title plaque (set by `PanelFrame`) |
| `Subheader` / `SubheaderInk` | Nunito bold | 20 | Names, row titles |
| `Body` / `BodyInk` | Nunito | 18 | Default text |
| `Caption` / `CaptionInk` | Nunito | 14 | Secondary details, column headings |
| `ResourceValue` / `ResourceValueInk` | Nunito bold | 18 | Amounts and costs |
| `TimerValue` | Nunito bold | 15 | Text over progress bars |
| `BadgeValue` | Nunito bold | 14 | Badge counts, icon captions |

14 is the smallest size. Text drawn over the game world or over coloured fills
(headers, values, button labels) carries a dark outline so it reads on any
background; text on parchment never has one.

## Spacing and sizing

Base unit 4 px, at the 1600x900 design resolution.

- Gaps: 4 inside a tight pair (icon + value), 8 default container separation,
  12 to 16 between groups, 24 between sections, 16 from the screen edge.
- Touch targets: buttons at least 52 high, icon buttons 52 minimum and 76 to 88
  for HUD actions, list rows at least 40.
- Icons: 24 to 32 inline, 40 to 64 in lists and cards, 84 or more as a subject.
- Window frames are at least 420 wide; content padding comes from the theme.

## Components

All surfaces are 9-slice textures from `tools/ui/build_textures.py`.

- **Window (`PanelWood` + `PanelParchment`)**: walnut frame with a gold band, a
  notched gold hairline and corner studs, drop shadow included. The crimson
  plaque (`PanelPlaque`) straddles the top edge; the close button sits on the
  top-right corner. Content goes on parchment.
- **Card (`PanelContainer` default, `PanelCard`)**: compact walnut panel with a
  gold rim for HUD modules, popups and toasts.
- **Chip (`PanelChip`)**: pill for HUD counters.
- **Wells (`PanelInset` on dark, `PanelInsetLight` on parchment)**: recessed
  slots for icons and sub-content.
- **Buttons**: a raised face with a gold rim on a darker ledge. Hover lightens,
  pressed drops onto the ledge (the label moves with it), disabled goes pewter
  grey, keyboard focus adds a glowing gold ring.
- **Tabs**: selected is gold with dark text and stands taller; unselected is
  walnut; the page is parchment.
- **Progress bars**: dark trough with a bronze rim. `ProgressBar` is green,
  `GoldBar` is for experience and capacity, `ConstructionBar` (blue stripes) is
  for anything counting down; use it through `TimerProgressBar`.
- **Inputs (`LineEdit`, `ItemList`)**: light parchment field with an inner shadow;
  focus turns the border gold; list selection is a gold bar.
- **Tooltip (`TooltipPanel`)**: near-black with a thin gold line. Tooltips give
  the exact value behind any abbreviated number.
- **CheckBox / radio**: use `CheckBoxInk` on parchment.
- **Dividers**: `divider.png` (gold, on dark) and `divider_ink.png` (on parchment)
  via `UiIcons.get_texture`.

## Icons

38 icons in `client/ui/icons/` (128 px PNG) with scalable sources in
`client/ui/icons/svg/`, all written out by `tools/ui/build_icons.py`.

Rules, enforced by the shared helpers in that script:

1. 128x128 canvas, subject within about 8..120, one drop shadow under the whole icon.
2. A 5 px `#2b1a0f` outline with round joins around every form.
3. Fills come from the fixed material gradients (gold, wood, stone, steel, red,
   green, blue, cream...), lit from the top left, with one soft highlight stroke
   and one flat shade plane at most.
4. One idea per icon, readable as a silhouette at 24 px. No text in icons.
5. Ids match game data: resources, troop types and building ids from
   `data/buildings.yaml` (a unit test checks every building model has an icon).

To add one: write an `icon_<name>()` function, add it to `ICONS` and to
`UiIcons.NAMES`, then run `tools/ui/build_all.sh`. Icon imports have mipmaps
turned on; show them with `UiIcons.make_rect` (or set `texture_filter` to linear
with mipmaps) so they stay clean when scaled down.

## Motion

- Fast and functional: 120 to 180 ms for hover, press and fades in; 250 to 300 ms
  for fades out and panels. Ease out on entry, ease in on exit.
- Buttons respond on press, not on release: the face drops 3 to 4 px.
- Windows fade and scale from 96% over 180 ms; toasts fade in 150 ms, hold 3 s,
  fade out 300 ms; modal scrim fades 150 ms.
- Counters tick towards their new value over about 400 ms instead of jumping;
  timers update every frame.
- Nothing loops forever except running timers. No flashing faster than 3 Hz.
  Motion never blocks input.

## Accessibility

- Contrast: every text pair is at least 4.5:1; `python tools/ui/contrast.py`
  prints the ratios and fails below that. Cream labels on the bright green and
  red button faces rely on their dark outline, so keep the outline.
- Scalable: the project stretches in `canvas_items` mode with `expand` aspect,
  so the UI scales with the window. Lay out with containers and anchors, never
  fixed pixel positions, and let text wrap or grow.
- State is never colour-only (icons, labels and disabled states back it up).
- Everything interactive is reachable by keyboard and shows the gold focus ring;
  `ConfirmDialog` focuses its confirm button and closes on `ui_cancel`.
- Abbreviated numbers always have the exact value in a tooltip.

## Regenerating assets

```bash
pip install -r tools/ui/requirements.txt     # resvg-py, Pillow, numpy
GODOT=/path/to/godot tools/ui/build_all.sh   # textures, icons, imports, theme

# Screenshots (needs a GPU, not --headless); then look at them
$GODOT --path client -s res://ui/screenshot_ui.gd -- res://ui/showcase.tscn docs/screenshots/ui_showcase.png 1980 1500
$GODOT --path client -s res://ui/screenshot_ui.gd -- res://ui/hud_mock.tscn docs/screenshots/ui_hud_mock.png 1600 900
```

- `tools/ui/common.py`: palette and SVG helpers.
- `tools/ui/build_textures.py`: 9-slice textures to `client/ui/theme/textures/`.
- `tools/ui/build_icons.py`: icons.
- `client/ui/theme/build_theme.gd`: builds `main_theme.tres` and the font
  variations. Slice margins there must match the texture script. Do not edit
  the `.tres` by hand; change the script and rebuild.
